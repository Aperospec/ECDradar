# 视频取得

## 先判用途，再选工具

能正常访问的视频可用于发现与核验；下载需确认素材取得方式和任务用途允许，跨平台使用还需核相应权利。自有素材、创作者明确授权、适用的开放许可或官方媒体使用条款均可成为依据，不要求每次都重新索取书面许可。

逐条区分：仅线索 / 允许内部取得 / 允许进入 ECD 使用。记录依据、允许的修改与用途、署名、是否覆盖声音 / 音乐及第三方画面；不能因下载成功就从前两种自动升级为再发布授权。纯线索不复用原资产；获授权编译可保留原视频主体并由 ECD 配中文解读，无需强制重画。

有官方媒体下载链接或创作者源文件时优先使用。通用平台可使用 yt-dlp；如工具不支持，尝试该站官方入口或已授权的合适替代工具。不要把“找视频”退化为仅输出软件下载建议。

## 有界下载

1. 选择具体视频和合理清晰度 / 文件大小；不批量抓整个账号、频道、帖子附件集或播放列表，不录制无期限直播。
2. 检查当前工具实际可用性和官方参数。只需已有音视频的单文件时不强加 FFmpeg；独立音轨合并才使用已验证的 FFmpeg / ffprobe。缺工具可在授权范围内从官方发行源取得并验证，不执行来历不明的在线下载站脚本。
3. 使用独立素材目录、不覆盖旧文件；忽略用户全局下载配置，不读取浏览器凭据，不自动载入额外插件或远程执行组件。有限重试，确认访问拒绝后停止该来源。
4. 保存原视频，不改变新闻语义、不去除权利标识；字幕、翻译、重剪或配乐制作交给后续任务。

yt-dlp 的单文件示例（先把变量设为已核实的 HTTPS 视频链接和本次独立绝对目录）：

```sh
yt-dlp --ignore-config --no-plugin-dirs --no-cache-dir \
  --no-playlist --playlist-items 1 --no-overwrites --restrict-filenames \
  --socket-timeout 20 --retries 2 --fragment-retries 2 \
  --max-filesize 200M --match-filter '!is_live' \
  -f 'b[ext=mp4]/b' -P "$RADAR_OUT" \
  -o '%(extractor_key)s-%(id)s.%(ext)s' -- "$RADAR_VIDEO_URL"
```

没有独立 CLI 但已有官方 zipapp 时，使用经过验证的 Python 3.10+ 执行该文件替代命令首词。实际文件大小仍应观察；流大小未知时上限不一定能预先判定，不能用它承诺绝对带宽上限。网站需要 JS 运行时、特殊格式或其他依赖时按具体需要核验，不以“支持某站”承诺所有 URL 都能下载。

官方说明：[yt-dlp](https://github.com/yt-dlp/yt-dlp#readme)。使用时核对应版本；不要自动自更新或启用 cookies-from-browser、用户名密码、Cookie 文件、netrc、DRM 绕过或无关插件。

## 下载后记录

只保存必要、非秘密的字段；不整包持久化可能含临时签名地址、请求头或账户信息的抓取元数据：

- 素材 ID、公开页面、创作者 / 权利人、原发布日期、取得时间、许可依据与使用边界。
- 本地绝对路径、实际大小、SHA-256、时长 / 分辨率 / 音轨的实测信息，工具与版本。
- 下载成功 / 失败及具体原因；不把进度 100% 等同于文件有效。
- 已完整观看 / 仅看片段 / 仅有转写 / 未观看；只对实际观察给看点和时间码。自动转写的专名、数字、否定、说话者需核对；不能只凭字幕推断画面。
- ECD 允许使用的片段、需保留的语境和署名、不得做的改动。只有确实观看后才能给出判断性的片段选择。

检查非空文件、媒体格式和可打开状态。有解码工具时检查流、时长并解码；条件不足就准确标“已下载，播放 / 内容尚未验证”。失败记录留在素材状态，不拖住其他候选。

本 Skill 的完成状态可以是“视频已取得，供 ECD 使用”或“内容值得做，视频仅作线索”；绝不是“已经剪完 / 可发布”。账号上传、剪辑成片和最终发布不在下载授权中。
