# ECDradar

从内容运营角度发现值得做的内容，核验、前期加工，再交给 ECD。

**版本：1.0.0 · Skill 名称：`ecdradar` · 调用：`$ecdradar`**

## 它做什么

- 美国优先，从 X、Reddit、视频平台、媒体与一手发布寻找 AI 新闻、新能力、新玩法和成果。
- 从时事、重大事件、节日与文化热点中发现可以结合 AI 的创作机会，如网站、数据分析、视觉或动画。
- 筛选时效、读者价值与原创空间，核实关键事实，提出创意种子并整理素材条件。
- 按需使用第三方工具取得许可范围内的视频，分别记录下载、观看、使用权利与待补事项。
- 输出可以交给 [ECD](https://github.com/Aperospec/ECD) 的选题简报，而不只是链接列表。

不限小红书。平台、受众、语言和已有运营原则由当前任务决定；没有更多上下文时，默认服务中文 AI 内容运营。

## 使用

将本仓库的 `SKILL.md`、`agents/` 和 `references/` 作为一个完整的 `ecdradar` Skill 目录，按你的 Agent 宿主方式安装。需要具备公开网页搜索 / 阅读能力；视频下载根据实际站点与授权条件使用可用工具。

示例请求：

> 使用 $ecdradar，找近三天美国为主的 AI 新消息、作品和能结合 AI 的热点，也找可取得的视频。按当前项目运营原则推荐值得做的内容，核验后整理成 ECD 简报。

也可以指定平台、受众、主题或时间窗口。没有 ECD 时，仍可交付独立简报；不会假称已经完成 ECD 审阅。

## 边界与依赖

ECDradar 不负责最终正文、标题组、版式、剪辑成片、商品化或自动发布。不绕过登录、付费墙、DRM 或访问控制，也不读取浏览器凭据。公开视频和可下载文件不自动等于可跨平台再发布素材。

ECD 与 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 等均为独立工具，本仓库不捆绑其实现、下载器二进制或第三方媒体。下载兼容性取决于具体链接、工具版本和访问条件；不承诺所有站点均可下载。

本仓库未附加新的开源许可证。
